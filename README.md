This is a fork of Manatee-open corpus search engine which is part of [NoSketch Engine project](https://nlp.fi.muni.cz/trac/noske).

Please note that the `main` branch does not contain any code. To obtain a concrete version,
please refer to a respective branch (e.g. `release-2.223.6`).

## How to build

0. make sure  `build-essential`, `libtool`, `autoconf-archive` are installed
1. clone the repository, make sure all the dependencies are installed (🚧 - list deps):
   * `libpcre3-dev`
   * `bison`
   * `libltdl-dev`
   * `swig3.0`
2. `autoreconf --install --force`
3. `./configure --with-pcre`
4. `make`
5. `sudo make install`
6. `sudo ldconfig`

For Ubuntu 26.04 (and other recent distributions without `libpcre3-dev` and `swig3.0`),
see the notes below.

## Ubuntu 26.04 installation notes

Ubuntu 26.04 no longer provides two of the required packages:

* `libpcre3-dev` (PCRE1) – Manatee includes `<pcre.h>` (PCRE1 API), so `libpcre2-dev` cannot be used as a replacement
* `swig3.0` – the `swig` package is SWIG 4, which is not compatible with Manatee's interface files


Both can be built from source and installed into separate prefixes under `/opt`, so they don't
interfere with the system versions.

### 1. Install the build tools

```bash
sudo apt install build-essential automake autoconf autoconf-archive libtool pkg-config bison libltdl-dev
```

### 2. Build PCRE 8.45 (last PCRE1 release)

```bash
wget https://sourceforge.net/projects/pcre/files/pcre/8.45/pcre-8.45.tar.bz2
tar xjf pcre-8.45.tar.bz2 && cd pcre-8.45
./configure --prefix=/opt/pcre1 --enable-utf --enable-unicode-properties
make -j"$(nproc)" && sudo make install
```

### 3. Build SWIG 3.0.12

```bash
wget https://sourceforge.net/projects/swig/files/swig/swig-3.0.12/swig-3.0.12.tar.gz
tar xzf swig-3.0.12.tar.gz && cd swig-3.0.12
./configure --prefix=/opt/swig3 --with-pcre-prefix=/opt/pcre1
make -j"$(nproc)" && sudo make install
```

### 4. Build Manatee

```bash
cd manatee-open
autoreconf --install --force
export PATH=/opt/pcre1/bin:$PATH     # makes pcre-config visible to configure
./configure --with-pcre SWIG=/opt/swig3/bin/swig \
    CPPFLAGS="-I/opt/pcre1/include" \
    LDFLAGS="-L/opt/pcre1/lib -Wl,-rpath,/opt/pcre1/lib"
make
sudo make install
sudo ldconfig
```

The `-rpath` flag records `/opt/pcre1/lib` in the built binaries and the Python module, so
`libpcre.so.1` is found at runtime without setting `LD_LIBRARY_PATH`.

### Troubleshooting

* **`pcre-config: command not found`** – PCRE1 is not installed, or `/opt/pcre1/bin` is not in `PATH`.
* **`fatal error: pcre.h: No such file or directory`** – `CPPFLAGS` does not point to the PCRE1 headers
  (`-I/opt/pcre1/include`).
* **`WARNING: 'aclocal-1.16' is missing on your system`** – the bundled generated files come from
  an older Automake version than the one installed. Run `autoreconf --install --force` (step 4) to regenerate them.
* **`'$function' was not declared in this scope`** – the Python wrapper was generated by SWIG 4.
  Check that `api/Makefile` refers to `/opt/swig3/bin/swig`. After switching SWIG versions,
  **delete the previously generated wrapper**, otherwise `make` will reuse it:
  ```bash
  rm -f api/*_wrap.cc api/*_wrap.cxx api/manatee.py
  ```
